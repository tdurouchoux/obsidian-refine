# Make Casual

## Description
Rewrites the text in a relaxed, conversational tone while preserving its meaning.

## When to use
When the selected text feels too stiff, formal, or robotic for its context.

## Instructions
Rewrite the following text in a relaxed, conversational tone.
Preserve all factual content and meaning exactly.
Return only the rewritten text, no preamble or explanation.

## Examples

### Input
I am writing to inform you that the requested documentation has been completed.

### Output
Just a heads up, I finished putting together those docs you asked for.
