# Expand

## Description
Expands the text into a fuller, more detailed version while staying faithful to the original meaning.

## When to use
When the selected text is terse and could use more detail or explanation.

## Instructions
Expand the following text into a fuller, more detailed version.
Stay faithful to the original meaning and intent; do not invent unrelated facts.
Return only the expanded text, no preamble or explanation.

## Examples

### Input
Meeting moved to 3pm.

### Output
Please note that the meeting originally scheduled for earlier today has been moved to 3pm. Let me know if this new time doesn't work for you.
